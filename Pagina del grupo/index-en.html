Abstract

This paper presents an algorithm designed for the mathematical modeling of harmonic signals, with the goal of representing them compactly and facilitating their analysis. To achieve this, the period is first identified. Once the period is found, that segment is modeled using a combination of mathematical functions: sinusoidal, exponential, step, and impulse. Anything that does not fit these functions is considered noise. Once the model is generated, the original data can be discarded to optimize storage. Subsequently, a new stage begins in which the signal is continuously monitored to detect outliers that do not correspond to the model. When an anomaly is detected, an alert is generated and data capture is activated again, so that the fault information is available for analysis. At the same time, the periodicity search process is repeated, and if one is found, the modeling cycle begins again. Thanks to its ability to represent information compactly and detect elements that deviate from expected behavior, this approach represents a significant advance in the monitoring of systems with a recurrent data flow. Furthermore, the integration of modeling and fault detection functions into a single algorithm opens up new possibilities for automation and real-time decision-making in sectors where signal stability is critical.
